API Endpoints

MethodPathDescription
GET /health Health check
GET /api/reminders?userId=<uuid> Fetch all reminders sorted by scheduledTime
POST /api/reminders Create reminder (JSON body)
PATCH /api/reminders/:id Update reminder fields or status
DELETE /api/reminders/:id Delete a reminder by UUID
POST /api/voice/process Upload audio → transcribe → parse → save

Features

AI Pipeline

Voice-to-Reminder

Record audio → Groq Whisper transcribes Hebrew → LLM extracts intent (title, time, phone, URL) → saves to DB. Timezone-aware (Israel +03:00).

Active

Manual Reminder Creation

Modal form with custom Hebrew calendar, hour/minute spinners, phone & URL fields. KeyboardAvoidingView + dismiss on tap outside.

Active

Smart Local Notifications

Auto-tiered scheduling: 1 week / 1 day / 2 hours / exact. Appointment keywords get extra 5-hour advance alert. Works in Expo Go.

Active

Reminder Dashboard

Tap to expand/collapse. Circle checkbox toggles completed (strikethrough). Overdue badge (עבר הזמן). Swipe left to delete. Quick-dial & quick-link. Pull-to-refresh.

UI Shell

Proactive Insights

ProactiveCard component for urgent AI-driven suggestions. Currently: static insurance renewal demo.

UI Shell

Grocery List

Smart frequency-based grocery suggestions with savings comparison. Receipt scanning placeholder.

UI Shell

Profile & Documents

Document upload placeholders (insurance, medical). User info display.

Active

Onboarding

Module selection (groceries, insurance, finance, appointments) with checkbox UI.

Notification Scheduling Logic

Time Until ReminderNotifications Sent
> 7 days🔔 1 week before → 🔔 1 day before → 🔔 2 hours before → 🔔 exact time
2–7 days🔔 1 day before → 🔔 2 hours before → 🔔 exact time
5h – 2 days🔔 2 hours before → 🔔 exact time
< 5 hours🔔 exact time only
Appointments (תור, רופא...)+ extra 🔔 5 hours before
